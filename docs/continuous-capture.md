# 연속 촬영

캔버스 에이전트 입력창 아래 ‘스킬’ 옆의 ‘연속 촬영’ 스위치를 켜세요. 마우스를 올리면 사용법을 볼 수 있어요. 설정은 프로젝트별로 저장돼요. 스위치를 끄면 기존 에이전트로 돌아가며, 연속 촬영 결과는 캔버스에 남아요.

## 촬영 순서

1. 제작 환경설정에서 이미지 모델, 영상 모델, 화면 비율을 선택하세요. 한 회차 분량의 대본을 캔버스로 가져오거나 에이전트에게 텍스트나 파일로 보내세요.
2. 연속 촬영을 켜고 ‘대본 분석’을 입력하세요. 앱이 장면과 샷을 나누고, 중복 에셋을 정리하고, 빠른 숏드라마 전개를 기준으로 완성 영상의 길이를 추정해요. 이 단계에서는 계획만 만들어요.
3. 해당 장면의 캐릭터, 소품, 장소와 시작 프레임 목록을 읽고 ‘계속’이라고 입력하면 에셋을 만들어요. 한 장면이 끝나면 다음 장면을 확인하세요. 같은 캐릭터, 소품, 장소의 에셋은 여러 장면에서 재사용해요.
4. 모든 장면의 에셋이 준비되면 다시 ‘계속’이라고 입력하세요. 각 장면의 첫 샷은 해당 장면의 시작 프레임을 사용해요. 나머지 샷은 바로 앞 클립의 실제 끝 프레임에서 이어 찍어요. 장면이 바뀌면 새 시작 프레임을 사용해요.
5. 에셋, 스토리보드 텍스트와 영상 클립은 캔버스에 남아요. 클립을 합치거나 더빙하려면 별도로 작업하세요. ‘계속’을 다시 입력하면 완료한 영상을 건너뛰어요.

계획을 바꾸려면 ‘다시 계획’과 함께 수정할 내용을 입력하세요. 기존 노드와 결과를 보관하며, 이름과 종류가 같은 에셋은 완료된 결과를 우선 재사용해요. 완료한 에셋의 원본 파일을 삭제했다면 복원해 주세요. 앱이 해당 에셋을 자동으로 다시 만들어 비용을 쓰는 일은 없어요.

## 클립 길이와 대사

클립은 최소 6초예요. 내장 H3의 최대 길이는 워크플로에 따라 15초 또는 10초이고, 완샹(Wan) Prime은 30초예요. Seedance 2.5 또는 Wan 3.0으로 식별하는 지원 연동은 최대 30초로 계획하며, 워크플로에 더 짧은 제한이 있으면 그 제한을 우선해요. 제한을 알 수 없는 사용자 지정 연동은 최대 15초로 계획해요. 서비스가 해당 길이와 시작 프레임 단독 입력을 지원하는지 확인하세요. 오디오나 끝 프레임 입력을 요구하는 것으로 확인된 워크플로를 선택하면 계획을 만들기 전에 연동을 바꾸라는 안내가 나와요.

한국어 대사는 자연스러운 발화 시간을 기준으로 잡아요. 중국어는 초당 약 4.5자, 영어는 초당 약 2.7단어를 기준으로 삼고, 말하는 사람이 바뀔 때의 호흡도 고려해요. 동작과 대사는 가능한 한 동시에 진행해요. 최대 15초인 모델이라면 21초 분량은 15초와 6초로, 25초 분량은 15초와 10초로 나눌 수 있어요.

계획을 만든 뒤 언어 모델이 장면 누락, 대사 원문, 화자, 순서와 말하는 속도를 확인해요. 바깥쪽 따옴표처럼 발화에 영향을 주지 않는 표기는 검토에서 제외해요. 앱은 JSON 구조, 에셋 참조와 모델의 길이 제한을 검사해요. 검토에서 문제가 발견되면 그 이유를 반영해 계획이나 해당 샷을 보완하고, 생성 전에도 대사 누락을 검사해요.

## 계획 저장과 작업 복구

- `src/services/continuous/`의 스케줄러에서 연속 촬영을 처리해요. 일반 에이전트의 의도 분류와 캐릭터·장면·스토리보드 추출은 별도로 작동하며, 연속 촬영은 프로젝트의 일반 `shots`와 원본 대본을 그대로 보관해요.
- `project.json`의 `continuousCapture`에 계획과 진행 지점을 기록해요. 캔버스의 ‘제작 계획 JSON’ 노드에서 장면별 에셋 ID와 영상 결과를 확인하고 복사할 수 있어요.
- 장면별 에셋 확인, 전체 에셋 점검과 촬영 시작 확인은 앱이 처리해요.
- 완료한 에셋은 건너뛰어요. 같은 장면은 앞 샷이 끝나야 다음 샷을 생성할 수 있어요. ‘현재 노드를 마치고 이후 작업 멈추기’를 사용하면 현재 요청이 끝난 뒤 대기열을 일시 정지할 수 있어요.
- 원격 서비스가 반환한 작업 ID를 저장해요. AutoDL, Zealman, 영상 중계 서비스와 ComfyUI는 각 연동에서 지원하는 방식으로 상태 조회를 재개해요. 요청 전송 후 연결이 끊겨 작업 ID를 받지 못했다면, 중복 과금을 피하기 위해 서비스의 작업 기록을 먼저 확인하세요.
- H3는 기존 여섯 부분 프롬프트 형식을 재사용하고, 다른 영상 모델에는 영어 연출 프롬프트를 전달해요. 사용자가 제공한 이름, 대사와 화면 문구는 원문을 보존해요. 이미지 이해 모델을 연결하면 참조 이미지 확인에 활용할 수 있어요.

오프라인 검증은 `npm run test:continuous`, `npm run test:agent`, `npm run test:comfy`로 실행할 수 있어요. 실제 클립의 연결 품질은 생성한 영상에서 확인하세요.
