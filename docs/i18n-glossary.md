## UI 말투 규칙

- 안내와 알림은 짧은 해요체로 써요. 사용자가 할 일은 ‘선택하세요’나 ‘입력해 주세요’처럼 알려요.
- 버튼, 메뉴, 탭, 라벨, 컬럼명은 ‘저장’, ‘다시 생성’처럼 명사형을 써요. 확인 질문은 ‘삭제할까요?’처럼 써요.
- 채팅 입력 예시는 작은따옴표로 감싸고, '전체 과정'처럼 앱이 인식하는 문구는 그대로 써요.
- 오류는 무슨 일이 있었는지 먼저 알려요. 오류 상세는 괄호에 넣고 보간 변수, 줄바꿈, 마크다운을 유지해요.
