# 갤러리 템플릿 생성 안내

내장 이미지 생성 도구로 각 템플릿을 한 장씩 만들었어요. 첫 번째 사용자 예시는 전체 화풍에, 두 번째 예시는 역동적인 동작과 원근에 참고했어요.

공통 프롬프트에는 흰 배경, 가는 회색 연필선, 얼굴 묘사가 없는 성인 데생 인형, 관절 원과 몸통 보조선, 전신과 충분한 여백을 지정했어요. 글자, 워터마크, 격자와 불필요한 물건은 제외했어요. 두 사람을 그릴 때는 선의 명암, 몸의 크기와 발이 닿는 위치로 앞뒤 관계를 나타냈어요.

- **한 사람 자세**는 무릎 꿇고 손 모으기, 한 다리에 체중 싣기, 달리며 내딛기, 다리를 꼬고 앉기, 쪼그려 앉아 팔꿈치 받치기, 발끝으로 서서 손 뻗기, 한쪽 무릎 굽히기, 팔짱 끼고 뒤로 젖히기, 팔을 들고 뛰기, 몸을 숙여 손 뻗기로 구성했어요.
- **두 사람 배치**는 마주 보고 대화하기, 나란히 서서 가리키기, 앞에 앉고 뒤에 서기, 대각선으로 앞뒤 배치, 등 맞대기, 앞서 걷고 뒤따르기, 손 내밀어 부축하기, 스쳐 지나가며 돌아보기, 떨어져서 손 뻗기, 앞에 웅크리고 뒤에 서기로 구성했어요.
- **역동적인 동작**은 공중에서 다리 펴기, 뒤로 공중제비 돌기, 두 손바닥을 앞으로 뻗기, 주먹을 원근감 있게 내밀기, 낮은 자세로 착지하기를 담았어요. 동작의 무게중심과 진행 방향, 원근에 따라 짧아 보이는 형태를 살리고 참고 이미지의 그림자, 속도선, 배치는 제외했어요.
- **추가 동작** 세 장은 세 번째 사용자 예시의 왼쪽 위, 오른쪽 가운데, 아래에 있던 자세를 각각 참고했어요. 옆에서 한 손을 짚고 몸 뻗기, 뒤에서 한 손을 짚고 낮게 앉기, 뒤에서 땅을 짚고 옆으로 뻗기예요. 시점, 손발을 짚는 지점과 다리를 뻗는 방향을 유지하면서 흰 바탕에 한 사람의 전신만 그렸어요.
- **캐릭터 디자인**은 짙은 남색 상의, 황토색 어깨 망토, 낡은 가죽 손목 보호대와 캔버스 천 우편 가방을 갖춘 산악 역참의 전령을 별도 프롬프트로 만들었어요. 왼쪽에 전신 정면과 뒷면, 가운데에 얼굴 정면, 오른쪽에 각도를 달리한 얼굴과 소재의 세부 모습을 배치했어요. 전체 영어 프롬프트는 [galleryTemplates.ts](../src/utils/galleryTemplates.ts)에 있으며, 앱에서 ‘프롬프트 보기’를 열어 바로 복사할 수 있어요.

완성본은 [public/gallery-templates/](../public/gallery-templates/)에 있어요. 파일명은 `앨범 번호-이미지 순번.jpg` 형식이며, JPEG로 압축해 앱과 함께 배포해요.
