# 튜토리얼: 剧流 Studio 처음 사용하기

이 글은 **어려운 용어를 파고들고 싶지 않은** 분들을 위한 글입니다. 순서대로 따라 하면 대략 다음 과정을 완료할 수 있습니다. 소프트웨어 열기 → 대화 모델 설정 → (선택 사항) 로컬 ComfyUI 연결 → 첫 이미지 생성.

더 짧은 「최근에 무엇이 바뀌었나요」는 [更新说明.md](../更新说明.md)를 참조하세요.

---

## 시작 전 준비

1. Windows 컴퓨터 한 대(현재 오픈 소스 안내는 Windows를 중심으로 작성되어 있습니다).
2. [Node.js](https://nodejs.org/) 설치(가급적 최신 LTS 권장).
3. (선택 사항) 로컬에 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)가 설치되어 실행 중이며, 브라우저에서 예를 들어 `http://127.0.0.1:8188`을 열 수 있어야 합니다.
4. 최소한 다음을 준비하세요.
   - 사용 가능한 **대규모 언어 모델**의 인터페이스 주소와 Key 한 세트(대본 작성, 대화식 설정에 사용). **또는**
   - 로컬 동영상만 편집하려면 AI를 먼저 설정하지 않고 바로 「동영상 편집」을 사용할 수 있습니다.

---

## 첫 번째 단계: 설치하고 열기

프로젝트 디렉터리에서 터미널(PowerShell)을 여세요.

```powershell
npm install
npm run electron:dev
```

[README.md](../README.md)의 「설치 및 실행」에 따라 Web 모드 `npm run dev`를 사용해도 됩니다.

메인 창이 나타나면 먼저 **설정**으로 들어가세요.

---

## 두 번째 단계: 언어 모델 설정(먼저 진행할 것을 강력히 권장)

언어 모델 = 「글을 쓰고, 스토리보드를 수정하고, 문서를 읽는 것을 도와주는」 모델입니다.

1. **설정 → 언어 모델**을 여세요.
2. 다음을 입력하세요.
   - **서비스 주소**(일반적으로 `https://某站/v1`과 같은 형태)
   - **API Key**(서비스 제공업체가 제공한 키로, 이 컴퓨터에만 저장됨)
   - **모델 이름**(서비스 제공업체 콘솔의 모델 ID)
3. 저장하세요.
4. 「연결 테스트」 버튼이 있으면 눌러 보세요. 성공은 네트워크와 키가 대체로 맞다는 뜻일 뿐, 모든 기능을 보장하지는 않습니다.

> Key가 없어도 화면을 열어 둘러볼 수는 있지만, 생성 관련 버튼은 대개 먼저 연동을 완료해야 합니다.

---

## 세 번째 단계: 「연동 도우미」로 다른 기능 설정하기(선택 사항이지만 편리함)

1. **설정 → 연동 도우미**를 여세요.
2. 업체 또는 중계 서비스의 **API 안내 문서**를 붙여넣으세요(개인 Key는 먼저 제거해도 됩니다).
3. 「이미지 생성 / 동영상 / 음성」 등 무엇을 설정하려는지 설명하세요.
4. 도우미가 입력을 마치면 해당 설정 페이지에서 **확인하고 저장**한 후, 자신의 Key를 추가하세요.

설정 페이지에서 여러 연동 설정을 계속 수동으로 입력해도 됩니다.

---

## 네 번째 단계: 로컬 ComfyUI 원클릭 추가(로컬에서 이미지를 생성하려는 경우)

1. ComfyUI가 실행 중이며 브라우저에서 해당 페이지를 열 수 있는지 확인하세요.
2. **설정 → 이미지 생성**으로 이동하세요(동영상을 만들 경우 동영상 설정으로 가도 됩니다).
3. **ComfyUI 원클릭 추가**를 사용하세요. 주소 예시: `http://127.0.0.1:8188`.
4. 저장하세요. 이 단계는 「Comfy를 인식한」 것일 뿐, **아직 결과물을 생성할 수는 없습니다**. 반드시 다섯 번째 단계를 진행해야 합니다.

---

## 다섯 번째 단계: API 형식 워크플로 붙여넣기(가장 막히기 쉬운 단계)

### 두 가지 형식 중 하나만 인식합니다

ComfyUI에서 워크플로를 저장할 때:

- **일반 저장** → 화면용 형식(내부에 nodes, 연결선 정보가 있는 경우가 많음) → **이 소프트웨어에서 바로 사용할 수 없음**.
- **Save (API Format)** → API 형식(노드에 class_type이 있음) → **이것을 사용하세요**.

### 剧流 Studio에 전달하는 방법

1. Comfy에서 **API Format**의 JSON을 내보내세요.
2. 설정으로 돌아와 해당 Comfy 연동 아래의 **「Comfy 워크플로 템플릿」** 영역으로 이동하세요.
3. 다음 중 한 가지 방법을 선택하세요.
   - 텍스트 상자에 붙여넣기 → **검증하고 저장**;
   - **파일에서 가져오기**;
   - JSON 주소 입력 → **가져오기**;
   - **Comfy에서 목록 새로 고침** 클릭(로컬에 목록을 조회할 수 있는 사용자 워크플로 파일이 있는 경우. 목록이 없으면 안내에 따라 붙여넣기를 사용하면 됩니다).
4. 「workflowTemplate 설정됨」과 같은 안내가 표시된 후 이미지 생성을 진행하세요.

팁: 워크플로에 `{{prompt}}`, `{{image}}` 등의 자리표시자를 넣을 수 있습니다. 생성 시 노드에 입력한 내용으로 바뀝니다.

---

## 여섯 번째 단계: 연결 테스트(선택 사항)

설정 또는 연동 도우미 과정에서 현재 주소의 연결을 테스트하세요.

- 연결됨: 최소한 해당 주소에 접근할 수 있다는 뜻입니다.
- Comfy에서 실제로 생성하려면 여전히 워크플로 템플릿이 있어야 합니다.

---

## 일곱 번째 단계: 첫 이미지(또는 동영상 한 편) 생성하기

### 이미지 생성

1. 프로젝트를 새로 만들거나 여세요.
2. 캔버스에 **이미지 생성** 관련 노드를 추가하세요(또는 프로젝트 템플릿의 이미지 노드를 사용하세요).
3. 노드에서 사용하는 모델/연동이 방금 설정한 Comfy 또는 다른 이미지 생성 연동인지 확인하세요.
4. 프롬프트 입력 → 생성 → 리소스 라이브러리 또는 노드 미리보기에서 결과 확인.

### 동영상 생성

과정은 비슷하며 동영상 노드를 사용합니다. Comfy에 연결했다면 마찬가지로 해당 **동영상용 API Format 워크플로**가 필요합니다. 이미 설정된 클라우드 동영상 모델을 사용할 수도 있습니다.

### 영상 편집만 하고 싶은 경우

홈에서 **동영상 편집**으로 들어가 로컬 동영상을 가져오면 됩니다. Comfy를 먼저 설정할 필요가 없습니다.

## 자주 묻는 질문(쉬운 설명)

**질문: 공지를 닫았는데 다시 나타나나요?**  
답변: 대개 관리자가 공지 내용을 업데이트했기 때문입니다. 같은 공지를 닫으면 반복해서 귀찮게 하지 않습니다.

**질문: 목록을 새로 고쳐도 비어 있나요?**  
답변: 원본 Comfy의 많은 버전에는 「완전한 워크플로 스토어 인터페이스」가 없습니다. 목록이 비어 있으면 API Format 파일을 붙여넣거나 가져오세요. 이는 예상된 동작입니다.

**질문: 키가 오픈 소스 저장소에 업로드되나요?**  
답변: 정상적으로 사용하면 키는 로컬 설정에만 있습니다. `.env` 또는 실제 Key를 Git에 커밋하지 마세요.

**질문: 그래도 설정 방법을 모르겠어요.**  
답변: 먼저 LLM만 제대로 설정하고 안내 문서를 연동 도우미에 전달하세요. Comfy는 다음 한 문장만 기억하세요. **주소 원클릭 추가 + API Format 워크플로 붙여넣기**.
